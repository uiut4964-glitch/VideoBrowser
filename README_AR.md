# متصفح التحميل (VideoBrowser)

متصفح أندرويد يكتشف الفيديوهات في الصفحات ويحمّلها.

## المميزات
- زر تحميل عائم (قابل للسحب): رمادي عند عدم وجود فيديو، **أحمر** مع عدّاد عند اكتشاف فيديو.
- عند الضغط عليه: يجلب كل الصيغ المتاحة (الجودات) مع الحجم والمدة ونوع الملف، وتختار الجودة.
- دعم ملفات مباشرة (mp4, webm, mkv, mp3 ...) وبث HLS (m3u8) بما فيه المشفّر AES-128.
- **تجزئة الملف**: عدة اتصالات متوازية (من الإعدادات)، مع **إيقاف مؤقت واستئناف** (حتى بعد إغلاق التطبيق).
- شاشة التحميلات: قيد التحميل / المنتهية، سرعة، تشغيل، مشاركة، حذف + إشعار أثناء التحميل.
- علامات تبويب متعددة، سجل، علامات مرجعية، نسخ ومشاركة الرابط، وضع سطح المكتب.
- الإعدادات: مسار التحميل، عدد الأجزاء، التحميلات المتزامنة، الصفحة الرئيسية، محرك البحث، Wi-Fi فقط، مسح السجل والكوكيز.

## تحديث 2
- الزر العائم يلتقط **الفيديو الذي يعمل فعليًا فقط** (الأكبر ظهورًا على الشاشة) ويتجاهل معاينات الفيديوهات الأخرى في الصفحة.
- شاشة اختيار الجودة جديدة: صورة مصغرة + اسم قابل للتعديل + المسار مع زر «تغيير» + قائمة فيديو/صوت بالجودة والصيغة والحجم + زر تحميل.
- مشغّل فيديو مدمج (يدعم قائمة التشغيل، التدوير، المشاركة).
- قوائم التحميل بالصور المصغرة وأيقونات واضحة وبطاقات منفصلة.
- حفظ التبويبات واستعادتها إذا أغلق النظام التطبيق، وزر في الإعدادات لتجاهل توفير البطارية، وأداة «سبب آخر إغلاق» لتشخيص الإغلاق التلقائي.

## طريقة بناء APK (GitHub Actions)
1. أنشئ مستودعًا جديدًا في GitHub وارفع **كل محتويات هذا المجلد** (مع المجلد المخفي `.github`).
2. افتح تبويب **Actions** ← سيبدأ البناء تلقائيًا (أو اضغط Run workflow).
3. عند الانتهاء افتح التشغيل ← **Artifacts** ← حمّل `VideoBrowser-APK` ← فك الضغط وثبّت الـ APK.
4. إن فشل البناء أرسل لي نص الخطأ وسأصلحه.

## حدود يجب معرفتها
- يعمل على أندرويد 10 فما فوق.
- لا يدعم: يوتيوب وما شابهه (روابط مشفرة/DASH)، المواقع المحمية بـ DRM (نتفليكس...)، وروابط `blob:` المجزأة.
- ملفات HLS تُحفظ بصيغة `.ts` (أو `.mp4` إن كانت fMP4) دون تحويل، وتُشغَّل في أغلب المشغلات مثل VLC و MX Player.
- لم يتم اختبار الكود على جهاز حقيقي بعد.
